    What we store, exactly

    When you shorten a link
    The link, its short code, when it was created and when it expires, plus a hash of your manage key. Never your name, email or IP address.
    When someone clicks
    The day, country, device type, browser family and the website they came from (domain only). No IP address and no cookies. Bots and link previews are not counted.
    To stop spam
    A salted hash of your IP address, kept for one minute so we can limit how fast links are created.
    Safety check
    New links can be checked against Google's Safe Browsing list. Only the link is sent, never anything about you.
    When you report a link
    The short code, the reason and your note. Not who you are. Reports are deleted after 180 days.
    Deleting
    Delete a link from your list and its click data goes with it. Expired links are cleaned up automatically.

    Our host, Cloudflare, handles requests the way any web host does. Don't take our word for the rest: the source code is public, including the database schema.

    Use it from your own code

    The same API powers this page. No key is needed.

    The reply includes shortUrl and a manageToken. Send the token as a Bearer header to read stats with GET /api/links/:code or remove the link with DELETE.
